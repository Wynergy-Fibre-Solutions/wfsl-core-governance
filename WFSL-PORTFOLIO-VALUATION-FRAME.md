\# WFSL Portfolio Valuation Frame v1.0



Status



Authorised



Binding



Non-revocable without Control Plane supermajority



\## 1. Purpose



This document defines how Wynergy Fibre Solutions Ltd (WFSL) communicates, measures, and defends portfolio value without relying on hype, sales pressure, or narrative persuasion.



WFSL valuation is framed as:



\- Capability value

\- Trust value

\- Execution value

\- Verifiability value

\- Sovereignty value



WFSL does not inflate figures.

WFSL does not claim certainty.

WFSL does not present valuation as a promise.



WFSL presents valuation as a disciplined range grounded in verifiable artefacts.



\## 2. Definitions



Portfolio value



The aggregate value of WFSL’s software, governance, verification systems, and execution capability.



IP value



Value attributable to the originality, reproducibility, and defensibility of WFSL system designs, code, schemas, contracts, and deterministic evidence patterns.



Trust value



Value attributable to independent verification, non-repudiation, and continuity of reliance across teams and time.



Execution value



Value attributable to demonstrable operational ability, including deterministic probes, verified builds, and converged ProofGate bundles.



Sovereignty value



Value attributable to independence from dependency capture and the ability to operate under WFSL governance without external narrative control.



\## 3. Valuation Rule Set



WFSL valuation statements must satisfy:



1\. Artefact anchored



A valuation statement must reference what exists, not what is intended.



2\. Range only



WFSL must communicate valuation as a conservative range, never a single number.



3\. Scenario explicit



WFSL must state which scenario a range belongs to.



4\. No implied certainty



WFSL must never imply that valuation ranges are guaranteed outcomes.



5\. Non-sale alignment



WFSL may value without intent to sell, but must still remain evidence-led.



\## 4. Portfolio Value Drivers



WFSL portfolio value increases when the following increase:



\- Number of converged guards producing deterministic evidence

\- Quality and clarity of ProofGate manifests and bundles

\- Cross-repo interoperability and composability

\- Institutional verification readiness

\- Operational reproducibility

\- Auditability under hostile review

\- Governance enforceability

\- Reduction of single points of dependency

\- Ability to function under constrained environments and partial failure



\## 5. Conservative Valuation Bands



WFSL uses the following internal bands, in GBP, for disciplined communication.



Band A: Foundation value



£0.5m to £2m



Criteria



\- Multiple repos with coherent standards

\- ProofGate manifests in key repos

\- Evidence emission present in at least two guard classes

\- Portfolio indexing and snapshot evidence exists



Band B: Converged trust value



£2m to £10m



Criteria



\- Multiple guards converged into repeatable pipelines

\- Control Plane snapshot and aggregation patterns exist

\- Admission and verification concepts are operational

\- Evidence and verdict artefacts exist and are reproducible



Band C: Institutional readiness value



£10m to £30m



Criteria



\- Cross-guard verification is repeatable across environments

\- Institutional Trust Track artefacts are embedded and maintained

\- External review can validate outputs without WFSL mediation

\- Governance contracts are coherent, binding, and measurable



Band D: Infrastructure operator readiness value



£30m to £75m



Criteria



\- Telecoms Infrastructure Track is operationalised into workflows

\- Field testing and handover artefacts are standardised and verifiable

\- WFSL can evidence infrastructure state and deployment truth

\- Federation strategy is implementable and enforced by artefacts



Band E: Sovereign systems platform value



£75m to £150m+



Criteria



\- WFSL composes trust, execution, and infrastructure into a platform

\- Devices and OS track becomes implemented as a deliverable system

\- Federation compatibility exists across jurisdictions

\- Operational adoption occurs without trust dilution



These bands are internal framing only.

They are not guarantees.

They are not market valuations.

They are discipline boundaries.



\## 6. Current Position Declaration



WFSL must maintain a current position statement in the Control Plane, derived from artefacts.



WFSL current position must include:



\- Date

\- Evidence references

\- Repos included

\- Guard classes converged

\- Weak points and gaps

\- Next concrete uplift milestone



WFSL does not declare “we are Band X” without listing the evidence basis.



\## 7. Non-Sale Value Posture



WFSL does not need to sell to be valuable.



WFSL value is treated as:



\- A resilience buffer

\- A credibility amplifier

\- A partnership lever

\- An institutional reliance surface



WFSL’s posture is:



\- Build first

\- Verify always

\- Monetise only where it does not distort truth

\- Partner only where evidence remains sovereign



\## 8. Prohibited Valuation Behaviour



WFSL will never:



\- Claim a valuation as fact without artefact basis

\- Use fabricated market comparisons

\- Use “GDP” language as if value equals national output

\- Confuse capability value with revenue

\- Present investor-style numbers without investor-grade diligence context

\- Inflate value to win approval or attention



Any breach is a governance fault.



\## 9. Deterministic Success Criteria



This frame is successful when:



\- WFSL can state value without hype

\- Institutions understand WFSL position in one page

\- External reviewers can map claims to evidence quickly

\- WFSL avoids narrative drift during rapid scaling
