# WFSL Release Checklist

## Purpose
Provide a deterministic checklist for cutting and sealing
WFSL governance releases.

## Pre-Release
- All artefacts complete and reviewed
- Authority verifier passes in authoritative repo
- Negative proof fails verification
- Release manifests updated

## Sealing
- Release tag created and signed
- Tag pushed to authoritative origin
- No force pushes performed

## Post-Release
- Archive manifest updated
- Post-release controls enforced
- Supersession policy referenced

## Verification
- Independent verification executed
- Results recorded in audit trail

## Rule
Checklist is executed once per release.
No retroactive modification permitted.

## State
Active.
