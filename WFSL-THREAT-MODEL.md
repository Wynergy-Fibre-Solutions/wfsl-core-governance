# WFSL Threat Model

## Purpose
Identify and constrain threat vectors relevant to
WFSL governance authority and release integrity.

## Threat Actors
- Malicious fork operators
- Supply-chain impersonators
- Insider misuse
- Key compromise adversaries

## Threat Vectors
- Tag spoofing
- Authority misrepresentation
- Registry omission
- Artefact mutation post-release

## Mitigations
- Signed, immutable tags
- Deterministic verification
- Authority registry enforcement
- Forward-only release discipline

## Residual Risk
Low, given cryptographic controls and audit traceability.

## Review
On superseding release only.

## State
Active.
