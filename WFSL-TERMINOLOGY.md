# WFSL Terminology

## Purpose
Provide precise definitions for terms used within the
WFSL Governance Core to prevent ambiguity.

## Definitions

Authority  
The formally asserted right to govern artefacts, established
only through signed WFSL release tags and registry verification.

Seal  
A signed declaration that a set of artefacts is final,
immutable, and governed under WFSL rules.

Supersession  
The act of introducing a new release that references and
extends a prior sealed release without invalidating it.

Registry  
The authoritative record used to confirm WFSL authority
during verification.

Verification  
A deterministic process that confirms whether an artefact
is WFSL-authoritative.

Negative Proof  
A demonstration that structurally valid artefacts without
WFSL authority fail verification.

Release  
A sealed set of governance artefacts identified by a signed tag.
